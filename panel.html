Telegram Notifications

Шаг 1. Создайте бота у @BotFather → получите токен.
Шаг 2. Узнайте свой chat_id (например, напишите боту @userinfobot).
Шаг 3. Интерфейс настроек — автоматический. Запустите команду Telegram: Send test message (палитра команд) — плагин сам поднимет страницу настройки и покажет её адрес в уведомлении. На странице: токен, подбор chat_id (напишите боту что угодно и нажмите «Найти чаты»), фильтр статусов и воркспейсов, кнопка «Тест отправки». Конфиг сохраняется в профиль пользователя — папка плагина остаётся нетронутой.
Шаг 3б. Вручную: node scripts\configure.mjs из папки плагина (для dev-копии можно и просто config.json).
Шаг 4. Палитра команд → Telegram: Open settings page — откроет страницу настройки в браузере (и Telegram: Send test message — проверит отправку).

Дальше всё автоматически: когда агент меняет статус на один из выбранных (по умолчанию done / attention / stuck / error / waiting / needs), в Telegram уходит сообщение. Повторы одного статуса гасятся антидребезгом (60 сек по умолчанию).

Панель — только инструкция: песочница панели не имеет доступа к файлам и сети, поэтому токен вводится в config.json. Список команд также виден в журнале воркера ниже (кнопка Logs).
